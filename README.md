# campaign-lab

![CI](https://github.com/Kimlong42/campaign-lab/actions/workflows/ci.yml/badge.svg)

Practice repo for *Applying Data Analytics in Marketing*: a **synthetic email-campaign A/B test**
generated by a seeded script, with planted effects and anomalies whose exact values are known,
so every test asserts a number instead of a range.

Planted facts (see `src/campaign_lab/generate.py`):

| what | value |
|---|---|
| customers | 4,000 (2,000 control / 2,000 treatment) |
| control conversion | 10.0 % |
| treatment conversion | 13.2 % → ATE = +3.2 pp |
| per-segment uplift | New +3 pp, Regular +5 pp, VIP 0 pp |
| duplicate rows | 20 |
| revenue without conversion | 15 |
| feedback mentioning "refund" | 30 |

```bash
make setup   # uv sync + pre-commit install
make data    # writes data/campaign.csv (git-ignored)
make lint
make test
```
